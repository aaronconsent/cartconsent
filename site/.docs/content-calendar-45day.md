# 45-Day Content Calendar — Consent Resolve

**Window:** Mon **2026-06-15** → Wed **2026-07-29** (45 days). Pairs with
`.docs/posting-system.md` (cadence, grid, repurposing loop) and
`scripts/video_scripts.py` (the 13 ~30s scripts).

## Operating principles
- **Front-load weeks 1–3** (6 videos/wk) to give algorithms signal, then settle
  to **5/wk** (TikTok) / 3–4 (others).
- **One video, many platforms** — same 9:16 file, captions/hashtags customized.
- **Judge on 3-sec retention + completion**, not followers, for 60 days.
- **A/B the first 3 seconds** — the back half re-runs top angles with a "B-hook".
- ≤2 posts/platform/day · `/demo` CTA · no competitor names.

## Production schedule (batch ahead — never produce day-of)
Render *next* week's slate in one batch the *prior* week:
| Batch (render by) | Produces |
|---|---|
| by Jun 14 | Week 1: invoice, leak, ftc, race, math, credit |
| by Jun 21 | Week 2: ghost, creepy, policy, twice, contrarian, ownership |
| by Jun 28 | Week 3: robot + B-hooks (invoice, leak, race, math, ftc) |
| by Jul 5 | Week 4 B-hooks |
| weekly after | Weeks 5–7 from retention data |

Command per batch (example Week 1):
```
ANGLE=invoice,leak,ftc,race,math,credit python3 scripts/gen_avatar_scenes.py
python3 scripts/finish_tests.py        # feed cuts → public/reels/test-<angle>-FINAL.mp4
python3 scripts/finish_variants.py     # TikTok-safe cut + .srt per video
```
**B-hooks:** add a 6-scene variant in `video_scripts.py` (new opening scene, same
body) under a new angle id like `race_b`, then render it the same way.

## Cost / credit planning
~$0.21/scene × 6 scenes ≈ **~$1.25/video**. Full 45-day slate ≈ **38 videos ≈ ~$48**
of HeyGen credit (TikTok cut + `.srt` reuse the same scenes — no extra spend).
Keep ~$10–12 of headroom per front-load week.

## Queue alignment (harmony with the written track)
To make the written VoC ad match the week's video theme, reseed the queue so the
matching `voc-<angle>` rows sort to that week. The angle ids here map 1:1 to the
`voc-*` slugs in `scripts/seed-voc-ads.py` (invoice, race, ftc, leak, twice,
ghost, credit, robot, policy, creepy, math, ownership, contrarian).
